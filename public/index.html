OBS 브라우저 소스 연동

방송 연동

OBS 스튜디오의 [브라우저 소스]에 아래 URL을 입력하면 투명 배경의 아바타가 방송 화면에 출력됩니다.

OBS 설정 권장 사항 가이드
  • 너비 / 높이: 1920 × 1080 (또는 아바타 크기에 맞춤)
  • FPS: 60 FPS 권장 (부드러운 모션 전환)
  • 장면이 활성화되면 브라우저 새로고침: 체크 권장
  • 표시되지 않을 때 소스 종료: 체크 해제 (즉각적인 리액션 유지)
  • 커스텀 CSS: body { background-color: rgba(0, 0, 0, 0); margin: 0; } (기본 투명 적용)
