연결 순서

  1. OBS 실행
  2. '소스 목록'의 + 버튼(소스 추가)
  3. '소스 유형' → '브라우저'
  4. '새 소스 생성'에 이름 입력(예: Virtually) → '소스를 표시' 켜기 → '새로 만들기'
  5. 속성 창에서 아래처럼 설정 → '확인'
  6. '소스 목록'에서 카메라 소스보다 위로 올리기
  7. 소스 우클릭 → '변환' → '화면에 맞추기'
